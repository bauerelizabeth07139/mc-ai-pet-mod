# MC AI Pet Mod

Minecraft AI宠物模组，为宠物添加智能行为系统。

## 特性

- **智能行为**: 宠物能够根据环境自主决策
- **多种模式**: 生存、建筑、护卫、扫荡
- **数量限制**: 支持最多50只AI宠物
- **跟随系统**: 可让宠物跟随指定玩家

## 命令

- /aipet spawn <count> - 生成AI宠物 (1-50)
- /aipet mode <survival|building|guard|sweep> - 切换宠物模式
- /aipet follow <player> - 让宠物跟随玩家
- /aipet stop - 停止宠物AI
- /aipet dismiss - 解散宠物
- /aipet count - 查看宠物数量

## 安装

1. 安装 Minecraft Forge (1.20.1)
2. 下载模组 jar 文件
3. 放入 mods 文件夹
